A simple library to work with JSON Web Token and JSON Web Signature based on the [RFC 7519](https://tools.ietf.org/html/rfc7519).

## Installation

Package is available on [Packagist](https://packagist.org/packages/KaziRayhan/jwt),
you can install it using [Composer](https://getcomposer.org).

```shell
composer require KaziRayhan/jwt
```
